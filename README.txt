BUILD THE APK (no Android Studio needed)
1. Create a free GitHub account and a new empty repository (private is fine).
2. Upload everything in this folder (including the hidden .github folder) to the repo's main branch.
3. Open the repo > Actions tab > "Build APK" > wait ~5 min until it turns green.
4. Open the finished run, download the "pages-apk" artifact, unzip it, and copy app-debug.apk to your phone.
5. On the phone, open the APK and allow "Install unknown apps" when asked.
